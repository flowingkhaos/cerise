Many platforms make arriving easy and leaving painful. Your posts live there in a format only
they can read. The day you want to move, you copy everything by hand.

cerise does the opposite.

## One button: Export

In the admin, **Export** downloads all your posts, drafts included, in a single file. Each post is
in **markdown**: plain text, with hashes for headings and dashes for lists. Any text editor opens
it, any other blog imports it.

You do not need to understand markdown to benefit from it. You only need to know it will still be
readable in twenty years.

## The code is open too

cerise is free software. Its code is public: anyone can read it, copy it and change it for their
own site. The editor you use here, in particular, is made to be a starting point for others.

<Callout type="note">
Open does not mean unprotected. The admin account, passwords and unpublished content stay private.
</Callout>

## What it means for a salon

Your blog is a shop window you build post by post, for years. It has to follow you if you change
host, designer or mind. With a simple format and open code, it does.
