At the chair, you never hesitate. You explain a treatment in three sentences, you answer the same
question for the hundredth time with a smile, and your client leaves knowing exactly what to
expect. Then you open a website editor and everything gets complicated: blocks, columns,
settings, an "Update" button that updates nothing.

cerise's editor starts from the other end. **You write, it formats.**

## Shortcuts you already know

There is nothing to learn. The moves are the ones of a slightly careful text message:

- Type `## ` at the start of a line: it becomes a subheading.
- Type `- `: you start a list.
- Type `> `: you quote a client (with her permission).
- `Ctrl` + `B` makes text **bold**, `Ctrl` + `I` makes it *italic*.

The text stays clean. There is no colour to pick and no font size to set: the page takes care of
that, the same way on every post.

## One page, one idea

A good salon post answers one question. "How long does a set take?" "What should I bring?" "Why
this price?" Write the question as the title and answer it below, the way you would out loud. If
a second question comes up, it deserves its own post.

<Callout type="astuce">
Read your text out loud before you publish. If you would not say it to a client, do not write it.
</Callout>

## And if you want to see the code?

One button switches the editor to source mode. There you see the raw text, in markdown: hashes
for headings, dashes for lists, asterisks for bold. It is the same text, written another way.
You can switch back and forth without losing anything.
