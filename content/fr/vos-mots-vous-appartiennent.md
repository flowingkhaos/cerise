Beaucoup de plateformes rendent l’arrivée facile et le départ pénible. Vos articles y vivent
dans un format qu’elles seules savent lire. Le jour où vous voulez changer, vous recopiez tout,
à la main.

cerise fait le contraire.

## Un seul bouton : Exporter

Dans l’espace d’administration, **Exporter** télécharge tous vos articles, brouillons compris,
dans un seul fichier. Chaque article y est en **markdown** : du texte simple, avec des dièses
pour les titres et des tirets pour les listes. N’importe quel éditeur de texte l’ouvre,
n’importe quel autre blogue l’importe.

Vous n’avez pas besoin de comprendre le markdown pour en profiter. Il suffit de savoir qu’il
sera encore lisible dans vingt ans.

## Le code aussi est ouvert

cerise est un logiciel libre. Son code est public : n’importe qui peut le lire, le copier et le
modifier pour son propre site. L’éditeur que vous utilisez ici, en particulier, est fait pour
servir de point de départ à d’autres.

<Callout type="note">
Ouvert ne veut pas dire sans protection. Le compte administrateur, les mots de passe et le
contenu non publié restent privés.
</Callout>

## Ce que ça veut dire pour un salon

Votre blogue est une vitrine que vous construisez article par article, pendant des années. Il
doit vous suivre si vous changez d’hébergeur, de designer ou d’idée. Avec un format simple et
un code ouvert, il vous suit.
